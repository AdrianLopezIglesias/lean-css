How to read this page

This is not a kitchen sink. Each entry is one HTML part: when to use it, a live demo, and a snippet you can copy.

This page itself is header + nav + main. On AdminCss that means a left index, because nav sits immediately before main.

header

Use for the introductory band of a page or of a nested region: brand, search, utilities. One page-level header as a direct child of body.

Do not use it as a generic colored bar inside a form or table.

Demo

Harbor Operations

Ada Chen

Snippet

<header>
  <p><strong>Harbor</strong> Operations</p>
  <p>Ada Chen</p>
</header>

nav

Use for a list of links that move the user: product sections, in-page index, breadcrumbs, bottom app tabs.

Position is the layout API. body > nav then main is a left rail. main then nav is a bottom bar. header > nav is site sections. main > nav is breadcrumbs.

Demo

Orders Customers Settings

Snippet

<nav>
  <a href="/orders" aria-current="page">Orders</a>
  <a href="/customers">Customers</a>
</nav>

main

Use once per page for the primary work or reading. Not chrome. Not the sidebar.

Do not nest another main.

Demo

This glossary's work area is the page main. You are in it.

Snippet

<main>
  <h1>Orders</h1>
  <!-- page task -->
</main>

aside

Use for complementary material: about box, subscribe, related notes. It is not the primary nav and not the main task.

Demo

About

The Long Coast is a small magazine about ordinary work next to water.

Snippet

<aside>
  <h2>About</h2>
  <p>Related, not the main essay.</p>
</aside>

footer

Use for closing matter of the page or of an article: status, copyright, secondary links.

Demo

12 unread · last sync 2 min ago

Snippet

<footer>
  <p>12 unread · last sync 2 min ago</p>
</footer>

section

Use when a region of the page is a named topic in the outline. It needs a heading. Think "Order 1042", "More from the coast", "Typography".

Do not use section to group form controls. Do not use it as an empty wrapper to make a box. If there is no heading, you probably want a div (rare) or a better landmark.

Demo

Order 1042

North Loop Market · packed, waiting on dock 2.

Snippet

<section>
  <h2>Order 1042</h2>
  <p>North Loop Market · packed.</p>
</section>

article

Use when the block could stand alone if you lifted it out: a blog post, a feed card, a glossary entry, a mail message.

Prefer article over section for a complete story or card. Prefer section for a chapter inside a larger page that is not itself a story.

Demo

Dock 2 is clear

Ada · 12 min ago

Pallets staged. Cups still short one sleeve.

Snippet

<article>
  <h2>Dock 2 is clear</h2>
  <p>Ada · 12 min ago</p>
  <p>Pallets staged.</p>
</article>

fieldset

Use inside a form to group related controls that the user fills together. The legend is the name of that group: "Filter this list", "Personal information", "New order".

Do not use fieldset as a page section, a card, or a sidebar. If there are no form controls, it is the wrong element.

Versus section: section is document structure (a topic with a heading). fieldset is form structure (controls with a legend). A filters toolbar is a fieldset. An order detail block is a section.

Demo

Filter this list

Snippet

<form action="#" method="get">
  <fieldset>
    <legend>Filter this list</legend>
    <label for="status">Status</label>
    <select id="status" name="status">
      <option>Any</option>
    </select>
    <button type="submit">Apply</button>
  </fieldset>
</form>

headings

Use one h1 for the page (or view) title. Nest h2–h6 without skipping. Headings name section and article blocks.

Demo

A working tide

What the list is for

A list is a way to stop carrying the day in your head.

Snippet

<h1>Orders</h1>
<section>
  <h2>Order 1042</h2>
  <h3>Line items</h3>
</section>

p

Use for a paragraph of prose. Put inline meaning in strong, em, a, mark, code, kbd — not in styled spans.

Demo

Press Ctrl + K to search. The SKU is FL-204. This is packed and waiting on dock 2. Same entry. Short one sleeve.

Snippet

<p>
  Press <kbd>Ctrl</kbd> + <kbd>K</kbd>.
  SKU <code>FL-204</code> is <strong>packed</strong>.
</p>

blockquote

Use for a quotation. Name the source with cite.

Demo

Keep the list short enough to finish before the weather changes.

— Dock board, unsigned

Snippet

<blockquote>
  <p>Keep the list short enough to finish before the weather changes.</p>
  <cite>— Dock board, unsigned</cite>
</blockquote>

pre

Use pre > code for a preserved code block. Use inline code for a short token in a sentence.

Demo

place: north loop market
person: ada
next: leave the crate at the side door

Snippet

<pre><code>next: leave the crate at the side door</code></pre>

ul

Use for an unordered collection: topics, tags, a set of peers. Not for primary navigation (that is nav with links) unless the nav really is a list of items.

Demo

  • Weather
  • Walking
  • Work

Snippet

<ul>
  <li>Weather</li>
  <li>Walking</li>
</ul>

ol

Use when order matters: steps, ranked items, a sequence.

Demo

  1. Sweep the dock
  2. Count the crates twice
  3. Leave the crate at the side door

Snippet

<ol>
  <li>Sweep the dock</li>
  <li>Count the crates twice</li>
</ol>

dl

Use for name/value pairs: order attributes, definitions, metadata. Not for a table of many rows (that is table).

Demo

Placed
17 Aug 2026, 07:41
Payment
Net 15 · paid
Ship to
14 Binder Street, North Loop

Snippet

<dl>
  <dt>Placed</dt>
  <dd>17 Aug 2026, 07:41</dd>
  <dt>Payment</dt>
  <dd>Net 15 · paid</dd>
</dl>

figure

Use for media or a diagram that has a caption. The image is img; the caption is figcaption.

Demo

Snippet

<figure>
  <img src="/coast.jpg" alt="Low tide along a stony beach" />
  <figcaption>North breakwater, last Tuesday.</figcaption>
</figure>

table

Use for tabular data: rows that share the same columns. Always th with scope. Not for page layout.

Demo

Recent orders
Order Customer Status
1042 North Loop Market Packed
1041 Ada Chen Paid

Snippet

<table>
  <caption>Recent orders</caption>
  <thead>
    <tr>
      <th scope="col">Order</th>
      <th scope="col">Customer</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>1042</td>
      <td>North Loop Market</td>
    </tr>
  </tbody>
</table>

form

Use when the user is submitting or changing a set of fields. Real action and method. Put related controls in a fieldset.

Demo

Snippet

<form action="/mail" method="post">
  <label for="to">To</label>
  <input id="to" name="to" type="email" />
  <button type="submit">Send</button>
</form>

label

Use a visible label for every control. Point for at the control id, or wrap the control. Do not rely on placeholder alone.

Demo

Snippet

<label for="sku">First SKU</label>
<input id="sku" name="sku" type="text" />

input

Use a real type: text, search, email, password, number, date, file, checkbox, radio, range. The type is the component. Do not fake an input with a div.

Demo

Snippet

<label for="q">Search</label>
<input id="q" name="q" type="search" />

<label>
  <input type="checkbox" name="photo" />
  Attach last photo
</label>

select

Use for a fixed list of choices. Prefer it over a custom dropdown.

Demo

Snippet

<label for="status">Status</label>
<select id="status" name="status">
  <option value="">Any</option>
  <option>Packed</option>
</select>

textarea

Use for multi-line text. Not a contenteditable div.

Demo

Snippet

<label for="note">Note</label>
<textarea id="note" name="note" rows="3"></textarea>

button

Use type="button" for in-page actions and type="submit" inside a form. Links navigate; buttons do something here.

Selected API (same across AdminCss and cinema): button.active or aria-pressed="true". Primary is type="submit". Cancel is value="cancel". Destructive is name="delete" or value="delete".

Demo

Snippet

<button type="button">New order</button>
<button type="button" aria-pressed="true">Selected</button>
<button type="submit">Save</button>
<button type="submit" value="cancel">Cancel</button>
<button type="button" name="delete">Delete</button>

details

Use for progressive disclosure: extra help, a rarely needed block. The summary is the only visible line until opened.

Demo

Why count twice?

The second count is a kindness, not a lack of trust.

Snippet

<details>
  <summary>Why count twice?</summary>
  <p>The second count is a kindness.</p>
</details>

dialog

Use for a modal task: compose, new order, confirm. Open with the native showModal() API. Do not fake a modal with a positioned div.

Demo

New order

Snippet

<button type="button" id="open">New order</button>
<dialog id="new-order">
  <h2>New order</h2>
  <form method="dialog">
    <button type="submit">Create draft</button>
    <button type="submit" value="cancel">Cancel</button>
  </form>
</dialog>

progress

Use for a known-max task: download, today's loop, 5 of 8. Not for a static score (that is meter).

Demo

5 of 8

Snippet

<label for="loop">Today's loop</label>
<progress id="loop" value="5" max="8">5 of 8</progress>

meter

Use for a scalar in a range: disk usage, a gauge. Not for an in-progress task (that is progress).

Demo

6 of 10

Snippet

<label for="load">Dock load</label>
<meter id="load" value="6" min="0" max="10">6 of 10</meter>
